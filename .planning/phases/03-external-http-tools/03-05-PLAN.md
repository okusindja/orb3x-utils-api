## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → translate_text | Untrusted text + language codes cross into the Google translate request |
| translation tool → Google (unofficial) API | Untrusted upstream that may fail or rate-limit |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-T1 | Denial of Service | oversized text → unofficial Google API | mitigate | `z.string().max(5000)` bounds input at the tool boundary (RESEARCH security recommendation, ASVS V5) |
| T-03-T2 | Tampering | language codes → request | mitigate | Zod `min(2).max(12)` + `sanitizeLanguageCode` regex `^[a-z-]{2,12}$` (double-validated) |
| T-03-T3 | Denial of Service | Google upstream failure/timeout | mitigate | 15s AbortSignal timeout; TranslationError caught → retryable isError; tool never 500s |
| T-03-T4 | Information Disclosure | error serialization | mitigate | Only code/message/statusCode + retryable/retryAfterSeconds serialized; no stack traces (Wave 1 filter) |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | Phase 3 installs zero new packages; no install task in this plan |
</threat_model>
