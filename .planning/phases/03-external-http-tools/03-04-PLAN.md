## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-N1 | Tampering | NIF input → portal request | mitigate | Zod `z.string().min(1)` + `sanitizeNif` regex `^[0-9A-Z]+$` after uppercase/trim before request (double-validated, ASVS V5) |
| T-03-N2 | Denial of Service | AGT portal timeout (both paths) | mitigate | 25s timeout on primary fetch AND TLS-fallback path; PortalLookupError caught → retryable isError with retryAfterSeconds; tool never 500s or hangs |

| T-03-N4 | Information Disclosure | error serialization | mitigate | Only code/message/statusCode + retryable/retryAfterSeconds serialized; no stack traces or TLS details leak (Wave 1 filter) |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | Phase 3 installs zero new packages; no install task in this plan |
</threat_model>
