| currency tool → Render exchange API | Untrusted upstream that may time out, be unreachable, or return malformed data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-C1 | Tampering | base currency → upstream URL | mitigate | Zod `z.string().min(2).max(20)` + `sanitizeCurrencyCode` regex `^[a-z0-9-]{2,20}$` validates before URL construction (double-validated, ASVS V5) |
| T-03-C2 | Denial of Service | Render upstream timeout/cold-start | mitigate | `AbortSignal.timeout(20000)` bounds the wait; CurrencyError caught and returned as retryable isError — tool never hangs or 500s; 60s cache cuts repeated cold-start hits |
| T-03-C3 | Information Disclosure | error message serialization | mitigate | Only code/message/statusCode + retryable/retryAfterSeconds serialized; no upstream secrets or stack traces (Wave 1 filter) |
| T-03-C4 | Tampering | module-level cache poisoning | accept | Cache populated only from successful API responses; no external write path (RESEARCH security domain) |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | Phase 3 installs zero new packages; no install task in this plan |
</threat_model>
