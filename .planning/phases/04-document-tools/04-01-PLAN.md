export async function generateReceiptPdf(payload: ReceiptPayload): Promise<Uint8Array>;

Runtime-required fields (else generator throws RouteError, status 400):
- invoice: `seller.name`, `buyer.name`, ≥1 `items[]` → `INVALID_INVOICE_PAYLOAD`
- receipt: `receivedFrom.name`, numeric `amount` → `INVALID_RECEIPT_PAYLOAD`
- contract: ≥2 `parties[]`, ≥1 `clauses[]` → `INVALID_CONTRACT_PAYLOAD`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → tool callback | Untrusted JSON payload (invoice/receipt/contract data) crosses into PDF generation |
| Tool callback → Vercel response | Generated base64 PDF crosses the serverless response body limit (~4.5 MB Hobby) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of Service | `pdfToolResult` / oversized PDF (many line items) | mitigate | **DOC-04 size guard (primary high-severity mitigation):** reject `Math.ceil(bytes.length * 1.34) > 4_000_000` with `RouteError('PDF_TOO_LARGE', ..., 413, { retryable:false })` BEFORE base64 encoding — client gets a structured `{ isError:true }`, never a raw Vercel 413. `maxDuration: 30` bounds runtime. |
| T-04-02 | Denial of Service | base64 memory inflation | mitigate | Guard runs on `bytes.length` arithmetic FIRST, before `Buffer.from(...).toString('base64')` — avoids materializing a huge base64 string only to reject it. |
| T-04-03 | Tampering | malformed/oversized JSON input → generator | mitigate | Zod `inputSchema` per tool bounds shape; generator `RouteError` (`INVALID_*_PAYLOAD`) on missing required fields; both surface as `{ isError:true }` via the shared mapping. |
| T-04-04 | Tampering | injection into PDF text / synthetic resource `uri` | accept | pdf-lib draws text literally (no template/script eval); inputs are plain strings. The `uri` is a fixed descriptive string (`mcp://orb3x/documents/*.pdf`), NOT a filesystem path — no path traversal. Low risk. |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase — pure composition of existing deps (`@modelcontextprotocol/sdk`, `pdf-lib`, `zod`, Node `Buffer`). Package Legitimacy Audit N/A. |
</threat_model>
